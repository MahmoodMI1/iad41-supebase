## What Is This

A real operations tool built to manage **130+ physical access readers** across a data center facility. Every door, every room, every rack — tracked, noted, and audited in one place.

This isn't a portfolio project. It's running in production.

---

## Features

| Feature | Description |
|---|---|
|  **Entries** | Full access directory grouped by section |
|  **Completed** | Mark readers as done and move them out of the way |
|  **Notes** | Inline field notes per entry |
|  **Change Log** | Every action timestamped and tracked forever |
|  **Filters** | Search by name, section, or type instantly |

##  Background

Data centers accumulate access debt fast — outdated reader names, worn stickers, misaligned badge codes. This tool was built to lead a full refactoring initiative across the facility.

Designed, built, and shipped independently under property management.
